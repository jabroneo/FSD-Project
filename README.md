# FSD Project

A classic-MySpace-inspired social platform built with React and Vite.

## Goals
- Customizable user profiles
- Nostalgic, expressive visual design
- Social features for a small community

## Tech Stack
- React
- Vite
- JavaScript
- ESLint

## Run Locally
1. Install Node.js (LTS).
2. Clone the repository.
3. Run `npm install`.
4. Run `npm run dev`.
